# AsyncFileDownloader
## Задача: "Асинхронный загрузчик файлов"
### Цель: Создать утилиту для скачивания нескольких файлов с ограничением:

Максимум 3 одновременных загрузки

Общее ограничение скорости скачивания (например, 1 МБ/с)

Прогресс-бар для каждого файла

Обработку ошибок и возможность отмены

# Что нужно сделать:
1. Реализовать класс FileDownloader:

   1. Ограничение параллельных загрузок через SemaphoreSlim

   2. Ограничение скорости скачивания

   3. Корректную обработку отмены через CancellationToken

   4. Добавить прогресс-бар:

   5. Отображение для каждого файла отдельно

   6. Общее количество активных загрузок
    
   7.   Обработать ошибки:
    
   8.   Проблемы сети
    
   9.   Отсутствие файлов
    
   10.   Отмену операции

# Дополнительные улучшения:

1. Возобновление прерванных загрузок

2. Валидацию URL

3. Проверку места на диске

Как проверить:
Запустите с реальными URL файлов разного размера

Попробуйте отменить через Ctrl+C

Проверьте ограничение скорости (можно уменьшить до 100_000 для наглядности)

Добавьте несуществующий URL для проверки обработки ошибок
